# Datheon Full Stack Web Development Internship

This repository contains four completed projects developed as part of the Datheon Full Stack Web Development Internship.

## Completed Tasks

### Task 1 — Personal Developer Portfolio
A personal portfolio website showcasing my profile, technical skills, projects, and contact information.

### Task 2 — Task Manager
A task management web application featuring task creation, editing, deletion, completion tracking, filtering, and local storage persistence.

### Task 3 — WeatherPulse Weather Dashboard
A responsive weather dashboard providing real-time weather information, city search, humidity, wind speed, atmospheric pressure, and a five-day forecast.

**Technologies:** HTML, CSS, JavaScript, WeatherAPI, and Vercel Serverless Functions.

**Configuration:** Set `WEATHER_API_KEY` in the environment variables before running the serverless API.

### Task 4 — ShopSphere E-Commerce Store
A responsive e-commerce storefront featuring product listings, search, category filters, shopping cart management, and a demonstration checkout flow.
